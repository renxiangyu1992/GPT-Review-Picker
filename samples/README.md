# Public samples

These files are synthetic documentation examples. They contain no operational identity, user profile, private project, or copied Handoff data.

- [`producer-request-v1.json`](producer-request-v1.json) demonstrates canonical Producer Request 1.0 authoring with `items`, the three public priorities, a task-result Agent Statement, and a small evidence set.

Before using the Request, replace its synthetic `project_root`, identity, names, timestamp, final response, and item paths with values from the current task. The listed sample evidence files are illustrative and are not included as real evidence.

Do not copy Request, Manifest, or Result files from `.gpt-review`, private acceptance artifacts, or real conversations into public samples.
